#  Antigone – Interactive Presentation

An interactive and responsive educational website dedicated to **Antigone**, the famous tragedy written by Jean Anouilh.

This project was developed to support a French literature oral presentation by providing a clear, structured, and interactive way to explore the play.

##  Live Demo

[ View Live Website](https://exposee-v2-5p366ac7v-mohamed-s-projects-lol.vercel.app/)

##  Features

- **Home:** Introduction to the project.
- **The Author:** Biography of Jean Anouilh.
- **The Play:** General information about *Antigone*.
- **Chronological Summary:** Main events of the story.
- **Characters:** Presentation of the main characters.
- **Antigone vs Créon:** Comparison of their ideas and values.
- **Main Themes:** Justice, freedom, duty, power, and rebellion.
- **The Conflict:** Understanding the central conflict.
- **Important Quotes:** Selected quotations from the play.
- **Interactive Quiz:** Test your knowledge with an interactive quiz.
- **Responsive Design:** Adapted to different screen sizes.

##  Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/med-ndr/exposee-V2.git
```

### 2. Navigate to the project directory

```bash
cd exposee-V2
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

##  Design

The website uses a dark theatrical aesthetic inspired by the atmosphere of ancient Greek tragedy.

- Dark backgrounds
- Off-white typography
- Dark red and gold accents
- Subtle animations
- Responsive navigation

##  About the Play

*Antigone* by Jean Anouilh is a tragedy inspired by the ancient Greek myth of Antigone. It explores the conflict between individual conscience and political authority.
