# Antigone — Exposition littéraire interactive

React + Vite + Tailwind CSS v4 + Framer Motion + Lucide React.

```bash
npm install
npm run dev      # développement
npm run build    # production (dossier dist/)
```

Toutes les illustrations (masque, colonnes, scènes du résumé, balance) sont des SVG originaux
dans `src/components/Illustrations.jsx` : aucune image externe, donc aucun lien cassé.
Le contenu est dans `src/data/` (personnages, thèmes, quiz, textes).
 link https://exposee.vercel.app/
